# MUX Dark

**Mahfuz's User Experience — a pure-black, translucent-cyan theme for Visual Studio Code.**

MUX Dark is a minimal dark theme built for developers who want a calm, focused workspace with a little more character than the default editor appearance.

## About the Theme

MUX Dark uses a pure-black editor background, near-black interface surfaces, and restrained cyan accents. The goal is to make the coding environment feel technical, clean, and distinctive without turning it into a wall of neon.

The theme applies its visual style across the VS Code workbench, including the editor, tabs, Explorer, Activity Bar, panels, terminal, status bar, menus, inputs, and other supported interface elements. Syntax highlighting uses a coordinated palette so code remains easy to scan.

### Color Palette

| Color | Hex | Used for |
|---|---|---|
| Pure Black | `#000000` | Main editor background |
| Near Black | `#05090B` | Secondary interface surfaces |
| Primary Cyan | `#00D9F5` | Active states and key accents |
| Secondary Cyan | `#00AFC8` | Supporting highlights |
| Muted Cyan | `#087F91` | Subtle details and borders |
| Primary Text | `#E6FAFC` | Important text |
| Secondary Text | `#8BAAB0` | General interface text |
| Muted Text | `#526A70` | Less prominent information |
| Success | `#35D49A` | Successful states |
| Warning | `#FFB84D` | Warnings |
| Error | `#FF5555` | Errors |

## Why I Made MUX Dark

The default VS Code theme can feel a little plain after spending hours in the editor. I wanted a theme with a stronger identity—something clean, technical, and enjoyable to look at during long coding sessions.

MUX Dark is my take on that experience: pure black, subtle cyan details, readable syntax colors, and a consistent look throughout the workspace.

I also made it with visual comfort in mind. Instead of filling the screen with bright neon colors, the theme keeps most surfaces dark, uses muted text for secondary information, and reserves brighter cyan for important elements. The intention is to create a less visually busy workspace that feels comfortable to work in for extended periods.

**A theme cannot guarantee eye health or prevent eye strain.** Visual comfort depends on your display, room lighting, brightness, contrast, text size, and individual needs. Take regular breaks and adjust your display settings to what feels comfortable.

## Design Philosophy

- Pure-black main background.
- Subtle translucent cyan-tinted surfaces.
- Thin, understated borders.
- Restrained accent colors instead of excessive neon.
- Compact, readable interface styling.
- Clear visual hierarchy for active, inactive, and status elements.
- No decorative backgrounds, gradients, animated effects, or unnecessary visual clutter.
